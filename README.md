Negotia AI

AI Agents Negotiate. x402 Enables Payments. Algorand Secures.

Overview

Negotia is an AI-powered agentic commerce platform where Buyer AI and Seller AI agents negotiate deals on behalf of users. x402 enables seamless AI-driven payment requests, while Algorand smart contracts securely lock payments in escrow and automatically release them when the agreed conditions are fulfilled.

Key Features

- 🤖 AI-powered Buyer and Seller Agents
- 💬 Autonomous AI Negotiation
- 💳 x402 AI Payment Protocol
- ⛓️ Algorand Smart Contract Escrow
- 💰 Secure Payment Settlement
- 🌍 Multi-language Support
- 💱 Multi-currency Support
- 🔐 User Authentication
- 📊 Reputation System
- ⚠️ Dispute & Refund Workflow

Tech Stack

- Next.js
- FastAPI
- Tailwind CSS
- Python
- Algorand
- AlgoKit
